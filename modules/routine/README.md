# 루틴 160

개인 운동·식사·수면·체중과 선택적인 개인 변화를 기록하는 한국어 대시보드입니다. 진단, 약물 처방, 효과 보장 도구가 아닙니다. 제공된 문서의 의학적 내용을 참고 안내로 옮겼으며 최신 지침을 독립 검증한 서비스는 아닙니다.

## 저장과 접근

현재 운영 버전은 Firebase Hosting과 Google 로그인을 사용하며 ChatGPT 구독이 필요하지 않습니다. 기록은 Firestore에 본인 계정별로 저장하며 브라우저에 영구 캐시하지 않습니다. 다른 기기에서도 같은 Google 계정으로 로그인하면 기록을 확인하고 수정할 수 있습니다. 인터넷 연결이 필요하며 동시 수정은 버전 충돌을 감지해 덮어쓰기를 거절합니다. 기존 Sites/D1 구현은 복구용으로 보존하며 새 사이트와 자동 동기화하지 않습니다.

개인 변화 기록은 저장 범위와 웹 전송에 동의한 뒤 활성화됩니다. 가림 모드는 화면 표시 설정이며 암호화가 아닙니다. 종단간 암호화를 제공하지 않습니다. 공유 기기에서는 로그아웃하세요. 민감 기록은 URL·콘솔·오류 메시지에 넣지 않습니다. 자동 분석·외부 AI 전송 기능은 없습니다.

## 백업과 복원

설정에서 JSON 백업을 다운로드합니다. 기본적으로 개인 변화 기록은 제외됩니다. 명시적으로 선택하면 포함합니다. JSON 파일은 암호화되지 않습니다. 복원 시 스키마·버전 검증, 기록 수 미리보기와 덮어쓰기 확인을 거칩니다. 민감 기록 미포함 백업을 복원할 때 기존 개인 기록은 기본적으로 유지합니다. 전체 데이터 삭제와 개인 기록만 삭제가 분리되어 있습니다. v1 등 알려지지 않은 버전은 거절하며 원본을 보존합니다.

## 구현

React + TypeScript + Vinext/Vite, Shadcn/Base UI, Cloudflare Worker/D1. 원문 요구와 달리 여러 기기 사용을 위해 인증된 서버 저장을 추가했습니다. 계획과 실제 기록은 별개이며 첫 사용에 실제 기록은 없습니다. 유산소 시간, 40분 세션, 근력 완료를 독립 집계합니다. 수면 미기록과 EHS 해당 없음을 0으로 바꾸지 않습니다. 주별 목표와 반복 일정의 적용 시점을 보존합니다.

## 실행

Node.js 22.13 이상, pnpm 사용.

```sh
pnpm install
pnpm dev
pnpm build
pnpm exec tsc --noEmit
node --experimental-strip-types --test tests/routine.test.mjs
pnpm exec drizzle-kit generate
```

현재 환경은 기본 PATH에 Node가 없어 번들 Node로 직접 실행했습니다. pnpm의 의존성 빌드 스크립트 승인 프롬프트가 있을 수 있습니다. 자동 다운로드된 pnpm 업데이트는 필요하지 않습니다. 미리보기는 개발용 가상 로그인이고, 배포 주소에서는 실제 ChatGPT 로그인과 본인 접근 제한을 사용합니다.

`tests/api.test.mjs`는 배포 빌드를 로컬 Wrangler 127.0.0.1:8787에서 실행하고 D1 마이그레이션을 적용한 뒤 실행합니다. 테스트에 사용되는 사용자 식별자는 무작위 가상 ID입니다. 실제 배포 데이터에는 테스트 기록을 만들지 않습니다.

## 검증 범위

- 계산·날짜 경계·수정/삭제·스키마·백업/복원: 자동 테스트 28개.
- 서버 API: 인증 거절, 계정별 격리, 저장 후 재조회, 오래된 버전 충돌, 다른 출처 요청 거절, 손상 입력 거절.
- TypeScript 검사 및 배포 빌드.
- 브라우저 클릭/스크린샷 QA와 실제 휴대폰·다른 컴퓨터 로그인 시험은 수행하지 않았습니다.
- WebMCP는 운동 기록창 열기 도구를 제공하며 저장하지 않습니다. 지원 실행 컨텍스트가 없어 런타임 도구 계약 검증은 수행하지 못했습니다.
- UI는 모바일 반응형입니다. 앱 설치·푸시 알림·결제·소셜 기능은 포함하지 않습니다.

## 알려진 제한

운동·식사 계획은 날짜별로 직접 수정할 수 있습니다. 운동 이름·종류·시작 시각·분량과 추가·삭제를 지원하며 수정은 선택한 날짜에 적용됩니다. 이전 데이터 버전의 자동 마이그레이션은 제공하지 않고, 검증 가능한 v2 백업만 복원합니다. 클라우드 저장 요청은 1.5MB로 제한되어 매우 많은 기록은 백업·정리가 필요할 수 있습니다.

## 운동 입력 개선

운동 기록 첫 화면에서 유산소 / 근력 / 둘 다를 고릅니다. 근력만 선택하면 유산소 구간을 입력할 필요가 없습니다. 시작 시각은 현지 시계의 HH:mm로 저장하며 아침/오후/저녁/밤/새벽 라벨을 함께 표시합니다. 기존 기록에 시각을 임의로 채우지 않습니다. 여러 종목과 메모는 접이식 추가 입력입니다. 시간 스키마 및 기존 백업 호환을 포함한 계산/백업 테스트는 총 30개입니다.

## 주간 식사 및 수면 시간표

식사는 월~일 계획/실제 두 영역이며 선택한 주와 날짜에 실제 기록을 연결합니다. 수면은 깨어난 요일을 기준으로 전날 20:00~당일 11:00을 표시하며 포인터 드래그는 15분 단위입니다. 같은 날 여러 구간을 만들 수 있고, 겹치거나 인접한 구간은 합칩니다. 구간 선택 후 저장 전 확인하며, 키보드/터치 사용자를 위한 시각 직접 입력도 제공합니다. 구간을 삭제하고 저장하면 변경됩니다. 수면 합계는 표시된 시계 구간 기준이며 DST 전환에 따른 실제 경과시간 차이는 별도 보정하지 않습니다. 표시 범위 밖 낮잠은 현재 시간표에 포함되지 않습니다. 기존 총 시간만 있는 기록은 시각 미기록으로 보존됩니다. 체중·BMI·칼로리는 4주 운동 및 기록 카드 옆에 이동했습니다.

수면 로직과 백업 검증 9개를 추가해 총 39개 계산/저장형식 테스트를 통과했습니다. 실제 브라우저 드래그 및 모바일 기기 QA는 수행하지 않았습니다.
